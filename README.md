### What I've been up to

🔧 Found a [silent weight-corruption bug](https://github.com/sgl-project/sglang/pull/40240) in SGLang's MoE LoRA kernel - shared experts were quietly reading the wrong adapter's weights. [Writeup here.](https://github.com/siddhant-rajhans/moe-lora-stride-aliasing)

📏 Got [InfiniteBench long-context eval](https://github.com/EleutherAI/lm-evaluation-harness/pull/3662) merged into EleutherAI's lm-eval-harness (+799 lines, 15 files)

🧠 Built [cortexlab](https://github.com/siddhant-rajhans/cortexlab) - a brain-encoding toolkit with custom Triton kernels for GPU voxelwise ridge regression. On [PyPI](https://pypi.org/project/cortexlab/) and [HuggingFace](https://huggingface.co/siddhant-rajhans). 21 stars and counting.
